# Сервис выполнения заданий

## Описание проекта

Сервис предназначен для выполнения различных задач через единый API. Он решает проблему разрозненного запуска операций и отслеживания их выполнения.

Пользователь отправляет запрос, система создаёт задачу (Job), выбирает подходящий обработчик, выполняет операцию и сохраняет результат или информацию об ошибке.

## Пользователи

Разработчики и приложения, которым необходимо запускать вычислительные и текстовые задачи через API.

## Основные возможности

- Создание задач и получение их идентификаторов.
- Выполнение вычислений и обработка текста.
- Отслеживание состояния задач.
- Получение результатов и сообщений об ошибках.
- Сохранение истории выполнения задач.

## Границы проекта

**В систему входят:**
- API для управления задачами.
- Диспетчер и реестр обработчиков.
- Обработчики вычислительных и текстовых задач.
- Хранение задач и результатов.
- Обработка ошибок и интеграция с внешним HTTP-сервисом.

**В систему не входят:**
- Веб-интерфейс и мобильное приложение.
- Обучение собственных моделей машинного обучения с нуля.
- Облачное развёртывание.

## Дальнейшее развитие

В дальнейшем планируется интеграция LLM для обработки запросов на естественном языке и автоматического выбора подходящего обработчика.
